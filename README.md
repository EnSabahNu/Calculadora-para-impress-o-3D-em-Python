# Calculadora-para-impressão-3D-em-Python
Meu primeiro projeto desenvolvido em Python.

A calculadora estima os custos de uma impressão 3D considerando:

- Peso da peça
- Preço do filamento
- Tempo de impressão
- Consumo de energia
- Desgaste da impressora
- Acabamento
- Valor de venda

O programa também calcula:

- Custo total
- Preço sugerido 2x
- Preço sugerido 3x
- Lucro
- Margem de lucro

## Tecnologias

- Python

## Objetivo

Projeto criado para praticar os fundamentos de Python e também auxiliar no cálculo dos custos das minhas impressões 3D.
